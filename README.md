# 房屋征收与调查管理系统

一套功能完整的房屋征收与调查数据管理系统，支持 PC 网页端和微信小程序端数据采集，涵盖调查管理、征收管理、审批流程、文书生成、审计日志等全链路业务。

## 仓库地址

- **GitHub**：https://github.com/whgxr/zscx
- **Gitee**：https://gitee.com/whgxr/zscx

## 功能特性

### 核心模块

#### 调查管理
- **动态数据表设计**：后台可视化自定义数据表结构，支持 20+ 种字段类型
- **数据录入**：PC 端和小程序端均可录入数据，支持图片/文件上传
- **数据查询**：灵活的搜索和筛选功能，支持高级筛选
- **数据导入**：Excel 批量导入数据，支持字段映射配置
- **数据导出**：支持 Excel 和 PDF 格式，4 种导出类型（标准/卡片/分组/表单）
- **导出模板**：可保存导出配置为模板，一键重复使用
- **分类管理**：数据表分类管理，支持拖拽排序
- **版本管理**：版本日志发布与管理，支持同步显示

#### 征收管理
- **征收模块**：独立的征收数据管理模块，与调查模块并行
- **LEVY_RELATION 关联**：征收记录与调查记录 1:1 关联，调查字段自动带入
- **数据变更同步**：调查数据变更后生成差异快照，征收负责人审核确认后同步
- **同步队列**：待同步请求列表，支持查看 before/after 差异对比

#### 审批流程
- **可视化流程设计器**：拖拽式审批流程设计，支持多级审批节点配置
- **节点类型丰富**：支持审批节点、条件分支、并行分支、抄送节点等
- **流程版本化**：每次发布自动版本管理，历史实例绑定对应版本号
- **两种触发模式**：手动提交审批 + 征收模块自动触发审批
- **审批操作**：通过/驳回/加签/转签/超时策略
- **专项动作审批**：针对数据新增/修改/删除/审查等操作，可按角色手动发起审批
- **审批中心**：统一入口，包含待办审批、我发起的、发起申请三个标签页

#### 表单设计器
- **可视化表单布局设计**：所见即所得的拖拽式表单设计器
- **6 列网格系统**：灵活的多列布局，支持单元格合并/拆分
- **字段拖拽排序**：自由调整字段位置和排列
- **文字竖向排列**：支持文字垂直方向显示
- **多选字段布局**：多选/复选框字段支持横向或竖向排列

#### 导出模板设计器
- **Excel 模板设计器**：可视化设计导出模板，支持公式计算
- **页面布局配置**：自定义页眉页脚、页边距、纸张方向
- **模板分类**：系统模板和用户自定义模板
- **设为默认**：一键导出，无需重复配置

#### 文书生成（Word 模板）
- **Word 模板编辑器**：在线设计征收文书模板（补偿协议、公示表、告知书等）
- **字段嵌入**：将数据表字段拖入文书模板
- **条件块与循环块**：支持条件显示和明细表循环渲染
- **A4 纸面预览**：右侧实时预览，字段高亮标出
- **一键生成与打印**：选择模板 → 生成文档 → 下载或打印

#### 权限系统
- **四级权限树**：模块级 → 分类级 → 表级 → 操作级
- **树型勾选**：三态复选框（全选/半选/未选），父节点勾选自动继承
- **细粒度操作权限**：查看/新增/编辑/删除/导出/审批/打印/设计模板等
- **多角色支持**：用户可挂多个角色，权限取并集
- **后端强制校验**：所有 API 操作均需权限校验，防止绕过

#### 审计日志中心
- **5 大标签页**：数据操作、审批记录、同步记录、文书生成/打印、登录登出
- **丰富过滤条件**：10+ 过滤维度，支持按时间/操作人/类型等筛选
- **Diff 对比**：数据变更 before/after 双栏高亮对比
- **导出 Excel**：审计结果可导出为 Excel
- **异常登录高亮**：异地 IP 或连续失败自动高亮标记

### 安全特性
- **单设备登录**：一个账号只能在一个设备上登录，新设备登录自动踢掉旧设备
- **会话超时**：用户不操作自动退出登录（默认 30 分钟，可配置）
- **JWT 认证**：HttpOnly Cookie 存储，安全可靠
- **密码加密**：bcryptjs 加密存储
- **乐观锁保护**：审批期间数据被修改时自动检测并提示

### 系统集成
- **微信登录**：支持微信小程序登录
- **飞书集成**：飞书 OAuth 登录 + 飞书 Webhook 消息推送
- **飞书 OAuth**：支持通过飞书扫码登录和账号绑定
- **仪表盘配置**：自定义首页展示内容

### 系统架构
- **前端 PC 端**：Next.js 14 + React 18 + TypeScript + Tailwind CSS + shadcn/ui
- **后端 API**：Next.js API Routes（一体化部署）
- **数据库**：MySQL 5.7+ / PostgreSQL 16
- **ORM**：Prisma
- **认证**：JWT + HttpOnly Cookie + UserSession 会话管理
- **微信小程序**：原生小程序
- **部署**：Docker + Docker Compose

## 快速开始

### 方式一：Docker 源码构建部署（推荐）

适用于服务器/NAS，直接从源码构建镜像。

1. 克隆项目
```bash
git clone https://github.com/whgxr/zscx.git
# 或从 Gitee 克隆
# git clone https://gitee.com/whgxr/zscx.git
cd zscx/docker
```

2. 复制环境变量配置
```bash
cp .env.example .env
```

3. 修改 `.env` 中的配置（特别是密码和密钥）
```bash
# Linux/Mac
nano .env
# Windows
notepad .env
```

4. 启动服务
```bash
docker compose up -d --build
```

5. 访问系统
   - 前端：http://localhost:3000
   - 默认管理员：admin / admin123

### 方式二：Docker 镜像拉取部署（NAS 推荐）

使用 GitHub Actions 自动构建的镜像，NAS 无需源码，压力更小。

1. 将 `docker-nas/` 目录下的文件上传到 NAS
2. 配置环境变量
```bash
cp .env.example .env
# 编辑 .env 修改密码和密钥
```

3. 拉取镜像并启动
```bash
docker compose pull
docker compose up -d
```

> 详细说明请参考 [docker-nas/README.md](docker-nas/README.md)

### 方式三：本地开发

#### 环境要求
- Node.js 18+
- MySQL 5.7+ 或 PostgreSQL 16

#### 安装步骤

1. 安装依赖
```bash
cd web
npm install
```

2. 配置环境变量
```bash
cp .env.example .env
# 修改 .env 中的数据库连接信息
```

3. 初始化数据库
```bash
npm run db:init
```

> 注意：使用自定义迁移脚本 `npm run db:init` 而非 `prisma db push`，以确保数据库兼容性。

4. 启动开发服务器
```bash
npm run dev
```

5. 访问 http://localhost:3000

## 数据导出功能

系统支持丰富的数据导出功能，Excel 和 PDF 两种格式均支持以下 4 种导出类型：

### 导出类型

| 类型 | 说明 | 适用场景 |
|------|------|----------|
| **标准列表** | 传统行列表格格式，一条记录一行 | 数据汇总、批量查看 |
| **卡片式** | 每条记录一个卡片，字段竖向排列 | 档案打印、信息卡 |
| **分组汇总** | 按指定字段分组，含汇总统计 | 分类统计、报表 |
| **表单式** | 每条记录一个表单页，Excel 每个记录一个 Sheet | 正式文档、档案表 |

### 自定义功能
- **字段选择**：自由选择要导出的字段，支持调整顺序
- **样式设置**：斑马纹、边框、列宽等
- **卡片布局**：卡片式可设置每行卡片数（1/2/3 列）
- **分组字段**：分组汇总可选择分组依据字段
- **表单布局**：表单式可设置每行列数（1/2 列）

### 导出模板
- 可将导出配置（类型、字段、样式）保存为模板
- 支持系统模板和用户自定义模板
- 可设置默认模板，一键导出
- 模板管理：创建、删除、设为默认

### 使用方式
1. 进入任意数据表页面
2. 点击右上角 **Excel** 或 **PDF** 按钮
3. 在弹出的导出对话框中：
   - 选择导出格式（Excel/PDF）
   - 选择导出类型
   - 选择要导出的字段并调整顺序
   - 设置样式选项
   - （可选）保存为模板
4. 点击 **导出** 按钮下载文件

## 微信小程序

### 开发步骤
1. 用微信开发者工具打开 `miniprogram` 目录
2. 修改 `app.js` 中的 `baseUrl` 为你的 API 地址
3. 配置小程序后台的服务器域名
4. 预览或上传发布

### 小程序功能
- 用户登录
- 数据表列表（支持调查/征收模块切换）
- 数据列表（搜索、分页）
- 数据详情（含关联调查记录）
- 新增/编辑数据
- 拍照/选图上传
- 审批待办入口
- 个人中心

## 部署更新

### 方式一：源码构建更新
```bash
cd zscx
git pull
cd docker
docker compose up -d --build
```

### 方式二：镜像拉取更新
```bash
cd /你的部署目录
docker compose pull
docker compose up -d
```

### 数据库迁移
项目使用自定义迁移脚本，兼容 MySQL 5.5+ 和 PostgreSQL 16：
```bash
# 在 web 容器内执行
docker exec -it zscx-web sh
node prisma/docker-migrate.js
npx prisma db seed
exit
```

> 注意：不使用 `prisma db push`，避免数据库兼容性问题。

## 数据备份与恢复

项目自带备份恢复脚本，位于 `docker/` 目录下：

```bash
# Linux/Mac
./backup.sh     # 备份数据
./restore.sh    # 恢复数据

# Windows
backup.bat      # 备份数据
restore.bat     # 恢复数据
```

手动备份：
```bash
# 备份数据库（MySQL）
docker exec zscx-mysql mysqldump -u root -p你的密码 --databases zscx --single-transaction | gzip > backup_$(date +%Y%m%d).sql.gz

# 备份上传文件
docker run --rm -v zscx_uploads:/data -v $(pwd):/backup alpine tar czf /backup/uploads_$(date +%Y%m%d).tar.gz -C /data .
```

> 完整部署文档请参考 [docker/DEPLOY.md](docker/DEPLOY.md)

## 技术栈说明

### 前端
- Next.js 14 (App Router)
- React 18
- TypeScript
- Tailwind CSS
- shadcn/ui (Radix UI)
- Lucide Icons
- React Flow（审批流程设计器）

### 后端
- Next.js API Routes
- Prisma ORM
- MySQL 5.7+ / PostgreSQL 16
- JWT 认证
- bcryptjs 密码加密
- UserSession 会话管理

### 文件上传
- 本地磁盘存储（Docker 卷挂载）
- 按月份分目录存储
- 支持图片和文件上传

### 集成
- 微信小程序登录
- 飞书 OAuth 登录
- 飞书 Webhook 消息推送

### CI/CD
- GitHub Actions 自动构建 Docker 镜像
- 推送到 GitHub Container Registry (GHCR)
